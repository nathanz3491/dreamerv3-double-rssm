# Outside audit, 2026-10-11: findings and fixes

Two rounds of outside code review were read against the code, and each claim
was checked before anything was changed. Round 1 (RSSM-2) is detailed in
[`rssm2-step-alignment.md`](rssm2-step-alignment.md). Status of every item:

| ID | Finding | Verdict | Fix | Affects |
|---|---|---|---|---|
| B01 | `action_deltas` sent actions 5-42 to DOWN | confirmed | only actions 1-4 move | training (map mode) |
| B02 | episode reset kept the old RSSM-2 state | confirmed | cleared at once; the reset step's action, the old episode's last, is also dropped from the movement sum | training and acting |
| B03 | batch path missed resets inside a window and pooled across episodes | confirmed | training scans the acting step | training |
| B04 | each window's state was handed back to its earlier steps (future leak) | confirmed | same scan: a step sees only closed windows | training |
| B05 | reset and steps share one random stream, so later evaluation worlds depended on earlier episode lengths | confirmed | `env.reseed(seed + i)` before each evaluation episode; world hash printed | **evaluation** |
| B06 | v2: a goal set before the replay window had its start state clamped, but its step count kept | confirmed | restart at the window's first step, with the count measured from there (`agent.goal_start`) | training (v2) |
| B07 | the first step of each episode was not shaped | confirmed | PHI of the start state is set at reset | training (shaped runs) |
| B08 | the codebook updated on batches with no valid change | confirmed | the update is skipped; revival draws only valid changes | training (v2) |
| B09 | `--greedy` still sampled | confirmed | new `policy(mode='greedy')` takes the argmax action and goal | evaluation tool |
| B10 | evaluator cutoffs were counted as deaths | confirmed; no reported number affected (cap 1200, longest episode 612) | endings split into death / timeout / cutoff; only deaths get a cause | evaluation tool |

| 6.3 | a zero change could still pass the cosine reach test | open risk | not changed; to test | v2 |
| 6.4 | the evaluation return includes shaping | true | raw and shaped return are reported separately | evaluation tool |

## Consequences for the results so far

- **Evaluation (B05):** "the same fixed evaluation worlds" held only for each
  run's first episode. From the second episode on, a run's worlds depended on
  how long its own earlier episodes lasted. Each checkpoint's own score is
  reproducible. But the 30-episode comparisons between runs were not paired
  world by world. Every run is to be re-scored with the fixed seeds; that
  needs no retraining.
- **Training (B01-B04, B06-B08):** every run with RSSM-2, shaping or the
  goal codebook is affected. B2, honest map, v1.2 and v2 are being rerun with
  all fixes (`~/run_fixq.sh`). The old runs stay on record as results of the
  older code.
